Site Defects – Combine

Combines everyone’s export ZIPs into one project folder and builds the combined project spreadsheet. Everything happens on this computer; nothing is uploaded.

Open this page in Microsoft Edge or Google Chrome on a Windows PC. It needs permission to read and write folders, which other browsers (and phones) don’t offer.

1 Folder with the new ZIPs (optional)

The folder you copied the export ZIPs into (from USB drives, OneDrive or email). ZIPs already combined are skipped quickly. Leave empty to just rebuild the combined spreadsheet, for example after resolving conflicts.

Not chosen

2 Where the combined project folder lives

The folder that holds (or will hold) the project folder, for example I:\Projects\267180.00 or C:\Inspections. The project folder “267180.00 Inspection” is created inside it. Always use the same place for a project.

Not chosen

3 Also copy the receipt to (optional)

A shared OneDrive or Teams folder the inspectors can open on their iPhones, so they can load the latest receipt themselves (Menu → Load PC receipt) without anyone sending it.

Not chosen

Close the combined spreadsheet in Excel before you start. Keep this tab open until it says Done.
